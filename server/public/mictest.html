Which one beeps?

Two ways of reaching the microphone. Run both with the volume up and listen. This settles whether the chime can be removed.

1 — Plain microphone

getUserMedia, the same call a video call uses. No speech recognition involved. Records 4 seconds, then stops.

2 — Speech recognition

The API Sotto uses today. Starts a dictation session for 4 seconds.

The question: did test 1 make any sound?

If test 1 was silent and test 2 beeped, the chime is tied to the speech API and can be removed by replacing it. If both beeped, it is tied to microphone access itself and no web app can avoid it.
