Can the chime be quietened?

Each test starts a 3-second dictation session a different way. Rate how loud the chime was. Volume up, phone off silent, no headphones — we want the worst case.

A — Plain start

The baseline. What Sotto does today.

B — With a silent audio track playing

Holds an audio session open first. On some systems that makes the OS duck or reroute its own alert sounds.

C — With a near-silent tone playing

Like B, but a real (almost inaudible) tone through Web Audio, which is a stronger claim on the audio session.

D — Mic opened first, then recognition

Takes the microphone with getUserMedia before starting recognition, so the input route is already established.
